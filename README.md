# NEUROATLAS

Локальная копия атласа нейрокибернетики и BCI: 116 учебных модулей, полноценные лекции, примеры, упражнения, самопроверка, 3D-карта и учебный план.

## Открыть на Mac

Дважды нажмите **Открыть NEUROATLAS.command**. Потребуется установленный Python 3 (на исходном компьютере он есть). Сайт откроется в браузере. Оставьте окно терминала открытым; Ctrl+C остановит сервер.

Другой способ: из этой папки выполните `python3 start.py`. Если порт 8765 занят, скрипт выберет свободный и покажет адрес. Не открывайте `dist/index.html` напрямую: браузер блокирует локальную загрузку модулей и JSON через file://.

Шрифты, библиотеки, лекции и 3D-геометрия находятся в копии и не требуют интернета. Внешние первоисточники открываются по ссылкам и требуют соединения.

## Прогресс

Прогресс, конспекты, результаты и настройки сохраняются в текущем браузере. На странице **Расписание** можно скачать резервную копию и импортировать её в другой браузер. Данные онлайн-версии и локальной версии хранятся отдельно; для переноса используйте экспорт/импорт. При импорте изученные темы объединяются, существующие заметки сохраняются, настройки плана берутся из копии.

Расписание — оценка учебного времени. Зависимости предшествуют новым темам; изученные модули пропускаются. Четверть времени отведена теории, 20% разбору примеров, 40% практике и 15% самопроверке. Календарь .ics содержит события на день без заданного часа.

## Проверки и разработка

Сайт статический; сборка не нужна. Изменяйте файлы в `dist/`.

Для полного набора тестов: Node.js 26+ либо совместимый 22.22.2+ / 24.15.0+, `npm ci`, затем `npm test`. jsdom используется только в тестах; сайт не зависит от npm. Набор проверяет данные, расписание, формы и сохранение в DOM, геометрию и жизненный цикл 3D-сцен. Он не заменяет проверку реального браузера, GPU, мобильных экранов и плавности анимации.

`generate-data.py` генерирует исходный каталог. Лекции хранятся отдельно в `dist/lectures-foundations.json`, `dist/lectures-computation.json`, `dist/lectures-systems.json`. Изменения каталога должны сохранять ID и совместимость прогресса.

## Источники и лицензии

В каждой лекции указаны первоисточники. Это авторский учебный материал для самостоятельного изучения, не профессиональная или клиническая квалификация. 3D-сцена пути сигнала — концептуальная иллюстрация.

Анимации основаны на официальной документации [Anime.js](https://animejs.com/documentation/): Timeline, ScrollObserver, SVG drawable, Scope и анимация JavaScript-объектов. Используется локальная версия 4.2.2. Three.js и шрифты также поставляются локально; лицензии сохранены в `dist/vendor/`.
